# Data Engineering & ETL

Practical examples and documentation covering Data Engineering,
ETL development, data integration, and data processing.

## Technologies

- Talend
- SQL Server
- Oracle
- PostgreSQL
- Snowflake
- Python
- REST APIs
- JSON
- Parquet
- Git

## Topics Covered

### 1. Context Management
Centralized configuration and environment-based context variable management for ETL jobs.

### 2. Error Handling
ETL error handling, logging, and job failure management.

### 3. REST API Integration
Retrieving and processing data from REST APIs using authentication and JSON processing.

### 4. SQL to Parquet
Extracting data from SQL databases and generating Parquet files for downstream analytics.

### 5. Incremental ETL
Processing only new or changed records instead of performing full data loads.
